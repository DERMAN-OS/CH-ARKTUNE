Why can Fretwork not hear my video automatically?

A web page is not allowed to listen to another site’s player. “Record tab audio” asks the browser for a screen/tab share — choose the tab that is playing the video and switch on Share tab audio. If your browser blocks that inside a preview pane, open this app in its own tab or download the video’s audio and use “Use audio / video file”. For YouTube, always follow the platform’s terms and use content you have the right to play.

Keys 1–8 trigger pads · M mutes the selected pad · Space stops everything. REC replaces a take but keeps the previous one under Undo. With snapping on, loops start and end on the grid. Recordings are de-hummed, gated and faded so they loop without clicks.

Microphone help

Checks on this page:

  1. Inside a preview pane? Browsers usually block the microphone there and no code can override it. Use Download app (or the download on the file card), then open the file in Chrome, Edge, Firefox or Safari.
  2. When the browser asks, choose Allow. If you blocked it earlier, click the lock icon beside the address bar, set Microphone to Allow, and reload.
  3. Check system privacy settings: Windows → Privacy → Microphone. macOS → Privacy & Security → Microphone. Close apps that hold the mic.
  4. No mic? Load an audio file. The tuner, chord finder and song tools all work from files.
