Chord shapes in this song

Record riffs, chords or vocals into the pads with no time limit. Tap a pad to record, tap again to finish, then tap to start or stop the loop.

Keys 1–8 trigger pads · M mutes the selected pad · Space stops everything. With snapping on, loops start and end on the grid. Recordings are de-hummed, gated and faded so they loop without clicks. There is no recording limit.

Microphone help

Checks on this page:

  1. Inside a preview pane? Browsers usually block the microphone there and no code can override it. Use Download app (or the download on the file card), then open the file in Chrome, Edge, Firefox or Safari.
  2. When the browser asks, choose Allow. If you blocked it earlier, click the lock icon beside the address bar, set Microphone to Allow, and reload.
  3. Check system privacy settings: Windows → Privacy → Microphone. macOS → Privacy & Security → Microphone. Close apps that hold the mic.
  4. No mic? Load an audio file. The tuner, chord finder and song tools all work from files.
